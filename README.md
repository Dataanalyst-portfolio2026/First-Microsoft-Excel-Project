# First-Microsoft-Excel-Project-By-Esther-Ayomide-Mogaji
Sales analysis project using Excel and Looker Studio to visualize revenue trends, category performance, and regional sales insights.

Businesses often struggle to identify which products, categories, and regions contribute most to revenue. This project demonstrates how sales data can be cleaned, analyzed, and visualized to answer key business questions and provide recommendations for improving performance. 

This project analyzed sales performance using Microsoft Excel and Looker Studio to uncover revenue trends, product performance, and regional sales insights. The goal was to transform raw sales data into actionable business intelligence that supports informed decision-making.

The dataset was cleaned by:
- Removing duplicate records.
- Handling missing values.
- Standardizing date formats.
- Correcting data inconsistencies.
- Preparing the data for visualization.

Tools Used
- Microsoft Excel
- Google Sheets
- Looker Studio
